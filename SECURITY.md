# Security Policy

## Supported versions

Security fixes are applied to the current default branch and the latest release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for a suspected vulnerability and do not include credentials, private planning content, or exploit details in public discussions.

Include:

- the affected skill and release;
- the smallest safe reproduction;
- the security impact;
- any known preconditions;
- a proposed mitigation, if available.

You should receive an acknowledgement within seven days. A fix timeline depends on severity and reproducibility. No bounty is promised.

## Scope

Reports about private-input leakage, unsafe credential handling, unintended external mutations, artifact verification bypasses, archive traversal, signing bypasses, and misleading security guarantees are in scope.
