# Support

Use GitHub issues for reproducible bugs and focused feature requests. Use the project showcase form for successful public projects.

Before filing a bug:

1. Confirm you are using the latest release.
2. Include the skill name, operating system, Python version, Git version, and exact non-secret error.
3. Remove credentials, private paths, `idea.md`, `plan.md`, and private project content.

Security issues must follow [SECURITY.md](SECURITY.md).
