# Governance

This repository is currently maintained by Satwik Sai Prakash Sahoo.

The maintainer decides scope, releases, and repository policy. Substantive changes use pull requests with passing required checks. Decisions should favor demonstrated user value, verifiable behavior, narrow permissions, and long-term maintainability.

Additional maintainers may be added after sustained, high-quality contributions and an explicit public announcement. No contributor or maintainer status is implied by automated or generated commit content.
